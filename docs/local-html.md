# 在引用浏览器中打开 HTML 文件

开发分支现已接入 DSH 内部的文件入口，尚未包含在 v0.2.0 发布包中。

在 DSH 文件列表或聊天中的 HTML 文件链接上右键，选择「在引用浏览器中打开」。已经打开文档预览时，也可以点预览工具栏里的同名按钮。它会在当前会话右侧打开文件，不另开浏览器窗口，也不启动本地网站服务。

打开后可引用选区文字、截图、圈画和写备注，也可点选页面元素后批注。确认「添加到草稿」后才进入输入框，仍需你自己发送。文件路径和加载版本会随引用保留，不会把临时的空白页或 Blob 地址冒充文件来源。文件修改后，请点重新加载读取新版。

## 第一次更新后

这次增加了本地 HTML 的大小、资源数和超时配置。更新开发版后，请从托盘完全退出并重启 DSH 一次；只刷新页面可能仍读到旧的配置表，并提示本地 HTML 配置尚未就绪。原有配置不需要手动补字段，新版会提供默认值。

## 哪些页面适合打开

首版适合自包含 HTML：内联样式、普通脚本，以及直接声明的同目录或子目录 `.css`、普通 `.js` 和常见图片。外部 HTTP 资源不由插件代为下载，能否显示取决于站点、网络和页面自己的安全策略。

它不是完整的网站开发服务器或依赖构建器。模块脚本、动态依赖、`srcset`／`picture`、CSS 二级本地依赖等形式尚不支持；保守检查也可能拒绝含有 `import()`／`fetch()` 等程序的文件。这时请使用打包成单文件的版本，而不是期待插件自动遍历目录或运行项目。

## 权限与限制

HTML 和明确声明的本地资源仍通过 DSH 当前会话的文件读取权限检查。依赖不能越出 HTML 所在目录；不会根据页面发来的消息去读取磁盘。页面脚本在隔离的框架中运行，不能取得 DSH 主页面或插件的文件读取接口。直接放开 `file://`、修改桌面安全策略和自动发送都不在实现内。

默认完整载荷上限为 16 MiB，最多 64 个直接本地资源，有限加载和读取请求超时为 15 秒。可在插件配置中调整 `localHtmlMaxBytes`、`localHtmlMaxFiles`、`localHtmlTimeoutMs`；等待用户点选元素不受这 15 秒限制。完整载荷包含包装与编码开销，原文件接近上限时也可能被拒绝，不会静默截断。

当前已覆盖授权读取、路径逃逸拒绝、隔离消息、来源、取消、导航变化和原生截图调用的定向测试。自动化中的 DOM／VM 测试不等同于实际 Electron 桌面验收；实页应检查文件加载、圈画、元素点选与草稿中图片和来源是否一致。
