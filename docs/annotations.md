# 圈画和元素批注

截图圈画和元素批注已包含在 **v0.3.0 正式版**中。安装或更新后，在「引用」菜单中选择对应操作。

## 在截图上圈画

在「引用浏览器」中打开网页，点击「引用 → 截图圈画与批注」。编辑器会固定当前可见画面的截图，你可以用矩形、画圈、箭头或画笔标出位置，再写上自己的备注。

画错了可以撤销，也可以清空标记。确认后点「添加到草稿」，带标记的图片和备注会加入当前对话；检查并发送后，Agent 才会收到。

这一方式不依赖页面内部有没有可读文字，所以也适合企微 Canvas 文档、视频画面或其他自绘界面。它只截图当前可见区域，不是整页长截图或 OCR，目前也不提供裁剪。

## 点选网页元素

点击「引用 → 点选元素并批注」，移动鼠标查看高亮，单击要讨论的元素。也可以按 Esc，或点工具栏的「取消点选」退出。

选定后会打开同一个截图编辑器，并自动框出所选元素。你可以继续圈画和写备注，再添加到草稿。引用还会带上元素的标签、结构定位、可见文字和位置等信息，方便 Agent 知道你指的是哪里；这些信息不是已核实的源码文件或组件位置。

点选使用临时覆盖层接收鼠标操作，不向原来的按钮派发点击，也不主动修改页面文字、样式或表单。退出时会移除覆盖层和临时监听。页面本来已注册的全局捕获脚本仍可能运行，不把它等同于对任意网站脚本的完全隔离。

无法逐个选择跨域 iframe、封闭 Shadow DOM、视频或 Canvas 内部的内容时，可以选外部容器，或者改用截图圈画。不会读取表单输入值、密码或编辑区域里的内容来补充元素说明；但截图仍可能包含页面上可见的敏感信息。

## 取消、页面变化与失败

取消、Esc 或关闭编辑器都不会向草稿添加内容。尚未添加的圈画和备注不是持久备份，切换会话、关闭页面或重启时不要依赖它们恢复。

截图在编辑期间不会偷偷重新抓取。网页导航或来源变化后，仍可查看当前标注，但会禁用添加，提示取消后重新捕获；不会把旧截图关联到新网址。

如果添加时草稿已经变化，或原生图片附件流程拒绝，合成图片和备注会进入现有的保留内容区。检查后可主动点「添加保留内容」，它会重新检查当前大小上限和插入位置，而不是再次截图。

## 数据和验证范围

只有明确开始圈画或元素点选时才捕获页面；不读 Cookie、登录对象、存储或系统剪贴板，不自动发送，也不提供实时 CSS 编辑。

发送时，合成 PNG 通过 DSH 原生图片附件交给模型，来源、用户备注和页面元素提示通过原生引用进入普通用户消息。页面提示仍标为外部不可信资料；正文和图片照常产生模型用量。

已覆盖绘图坐标缩放、元素与图片位置映射、PNG 编码、取消清理、页面/会话变化、草稿修订检查和失败保留的定向测试。独立组件的浏览器预览不等于原生 DSH 中的完整操作验收；真实桌面里的点选、标注及入稿仍需按同一流程实页确认。
