# 本地 HTML 验证记录

本记录对应独立插件开发分支的本地 HTML 功能，不是 v0.2.0 已发布附件的验证声明。

## 安装版接口

只读核对安装包：DSH Desktop 0.2.2-rc.1，构建提交 `c59d10aff167ad7eefead4b3a9082fb57c8fbfe8`。已安装客户端提供 `contextMenus.register({target:'file'})`；文件列表、聊天文件链接与预览中的文件目标均携带来源会话和路径。导航使用 `sidebarRight.openTabIn`，不从当前选中的会话猜测来源。

原生 guest 仍使用官方保留的 `about:blank#lease` 初始页。文件内容只进入 `sandbox="allow-scripts"` 的不透明子框架，不开放 `file://`，不添加 `allow-same-origin`，不改已安装文件、原生权限处理或导航限制。

## 已执行的检查

插件定向回归：23 个文件、705 项测试通过；随后完成独立插件构建和构建后 noEmit、Host 配置与客户端模块注册检查。测试覆盖菜单的真实 Cordis fiber 撤销、来源会话、授权读取、静态资源、路径逃逸拒绝、预算、取消与未决读取、重载、新 guest、框架导航、原生截图调用和来源元数据。

从构建后的客户端产物提取实际运行时函数，生成无需服务器的独立浏览器检查页。真实浏览器中首次就绪返回 `frameGeneration: 1`；直接样式、脚本和 SVG 资源正常显示，测试脚本无法访问父页面文档。点选返回内页 `button` 而不是外层 `iframe`，文字与可见按钮一致，普通按钮点击处理未被点选触发。加入框架焦点转移后，再次验证直接按 Esc 可返回 `cancelled`；取消后可重新进入点选并成功选择。控制台没有记录错误，验证标签页已关闭。

## 共享正文解析

本地 HTML 已增加固定的 `article` 操作，直接使用网页引用的同一 Defuddle 执行入口；消息不携带可执行代码。补充后 24 个文件、720 项测试通过，并完成构建和构建后检查。真实官方 UMD 的测试确认：直接网页与不透明内页得到相同 Markdown；用户测试页也能识别正文；导航、来源、完整预算、无网络提取和失败回退保持约束。

使用最新编译代码的独立浏览器页载入用户测试用的自包含 HTML，不选择文字，点击正文操作后成功得到 `article`／`markdown`、原测试页标题与正文，控制台没有错误。此检查仍不是原生 DSH 草稿完整端到端验收。

## 未验证的范围

上述浏览器检查是隔离框架和实际编译代码的验证，不是 Electron 原生 guest 的完整端到端验收。Node／DOM 测试中的原生截图接口由受控 guest 提供，不代表已经在真实桌面取得 PNG。

桌面实页仍需确认：在文件列表和聊天文件链接右键打开；首次 guest 绑定与子框架加载时序；真实截图圈画及元素框的位置；原生图片和文件来源加入正确草稿；取消、重载和切换会话不误入稿。新增 Host 配置第一次加载需要完整重启桌面版，不能以只刷新客户端代替。
